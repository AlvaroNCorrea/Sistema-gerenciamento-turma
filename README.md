# 🏫 Sistema de Gerenciamento de Turma (Turma AD6)

Este é um projeto simples desenvolvido em Python para gerenciar o cadastro de professores e alunos de uma turma específica. O sistema utiliza estruturas de dados em dicionários e listas, além de funções dinâmicas com interação via terminal para organizar e atualizar os dados.

## 🚀 Funcionalidades

- **Visualização de Dados**: Exibe de forma organizada a lista de professores e alunos cadastrados.
- **Cadastro Dinâmico**: Permite a adição de novos professores através da entrada do usuário no terminal.
- **Estrutura Base**: Desenvolvido utilizando dicionários de listas, garantindo facilidade na manipulação de dados.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** [Python 3](https://www.python.org/)
* **Paradigma:** Programação Estruturada / Funcional

## 📋 Pré-requisitos

Você precisa apenas do Python instalado em sua máquina (versão 3.x recomendada) ou pode rodar o código diretamente no Google Colab / Jupyter Notebook.
